# AdmitPath

College admissions counseling platform.

This repository currently contains the **front-end website** only — a fully
responsive, interactive marketing site plus role-based demo dashboards built with
HTML, CSS, Tailwind CSS, Bootstrap 5 and vanilla JavaScript.

- Source & how to run: [`frontend/README.md`](frontend/README.md)

## Quick start

```powershell
cd frontend
python -m http.server 5500
# open http://localhost:5500/
```
